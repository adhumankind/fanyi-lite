# 宇宙无敌超级霹雳便捷的网页翻译工具 (v0.8.8)

作者：阿帝。专注 Alt+1 一键全文翻译的高性能 Chrome MV3 扩展，采用纯正**美拉德色系（Maillard Aesthetic）**排版。

## 🌟 核心能力

| 维度 | 能力 |
|---|---|
| **多语种互译** | 源语言全语种自动识别（含阿拉伯/希伯来/泰/希腊/印地等）；目标语言可选简体中文/繁體中文/英/日/韩/法/德/俄/西 |
| **行业专业翻译** | 8 大行业预设术语库（技术/学术/医疗/法律/金融/电商/游戏/工业）+ URL 自动识别 + 用户自定义术语表，占位符保护引擎保证术语译名全文一致 |
| **国内外双引擎** | Google 免费接口 + 国内极速直连通道（免翻墙 100% 可达），智能降级自动切换，支持锁定单引擎与一键连通性自测；国内通道单查询硬限 500 字符（实测按解码字符数计），已按 460 预算分句切分、触限自动对半切分自救、空响应段落级回退原文，中日韩目标语言分块拼接无空格 |
| **呈现模式** | 译文跟随（美拉德注释译文）/ 译文替换（译文=原文100%原生排版）/ 原文跟随（译文套用原文主样式、原文对称穿美拉德注释——注释字号按【父级上下文】计算不再放大成巨型字、深色页面自动反转为暖奶白、按钮/独立链接内的原文豁免注释化保持原生可读）；JS inline style 直拷宿主计算样式（字号/字重/颜色/行高），块级容器内部插入防折行防抛飞，切换即时生效 |
| **交互单元保真** | 按钮/胶囊/独立链接内的译文在三种模式下均与原件 100% 同款排版（同字号/同色/同字重，紧凑中线分隔）；导航菜单项/标题链接/表格单元格链接随宿主整体翻译（不再漏翻），整段是单个链接时译文自动套同款克隆链接（替换模式下点击行为不丢失）；原件里的 SVG 箭头等图标在替换模式下依然保留 |
| **性能** | 4 路并发工作池 + 流式逐步上屏，首批译文 0.5s 呈现；术语正则预编译缓存；长文总耗时约为串行的 1/4 |
| **SPA 支持** | hook pushState/replaceState + popstate/hashchange 监听，客户端路由切换自动重置并联动"总是翻译" |
| **视觉** | 美拉德琥珀双色排版：深茶浓缩褐（浅底 12.5:1）/ 高透亮暖奶白（深底 13:1+）/ 琥珀渐变立柱 + 盘古中西空格距 + 深色按钮反色 + Flex 大标题防竖排 |
| **图标** | 美拉德纯色块「译」字双态图标（#b45309 琥珀焦糖满幅圆角色块 + 暖奶白粗体「译」，撑满图标区域），未翻译=纯色块，翻译中/已翻译=沿轮廓一圈流动彩虹渐变描边（全色谱 conic 环绕，宽约 10%），16px 字形依然清晰可辨 |
| **触发逻辑** | 默认 Alt+1 手动切换；可选"总是翻译"进入外文页自动翻译（含 SPA 新路由） |

## 🚀 安装使用

1. `chrome://extensions/` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择本目录（`fanyi-lite/`）；
2. 打开任意外文网页按 **Alt+1**：图标常亮百分比进度、顶部弹出美拉德 Toast、译文流式上屏；
3. 再按 **Alt+1** 一键还原；点击扩展图标可切换模式/语言/行业/总是翻译；扩展"选项"页可配置引擎策略与自定义术语表。

## 📁 目录结构

```
fanyi-lite/            ← 扩展本体（加载此目录）
  manifest.json        ← MV3 配置（Alt+1、图标、权限）
  background.js        ← Service Worker（双引擎降级/国内直连/Badge与图标状态机）
  content.js           ← 内容脚本（段落提取/术语引擎/并发流水线/渲染与SPA感知）
  style.css            ← 美拉德排版系统（三模式/深浅色/上下文自适应）
  popup.html/js        ← 弹出面板（模式/语言/行业/总是翻译）
  options.html/js      ← 设置页（引擎策略/连通性自测/自定义术语表/快捷键）
  icons/               ← 双态透明底图标 16/32/48/128
screenshots/           ← 视觉验收截图与排版演示页（非扩展运行文件）
```
