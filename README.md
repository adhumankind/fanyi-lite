# 宇宙无敌超级霹雳便捷的网页翻译工具

> 作者：阿帝 · Chrome MV3 扩展 · 美拉德（Maillard）美学 · 当前版本 v0.8.7

按下 `Alt+1`，整页外文瞬间变成中文；再按一次，完整还原。设计目标：**快、干净、样式零破坏**。

## ✨ 特性

- **一键全文翻译**：Alt+1 手动开关，可选「总是翻译」自动模式；SPA 路由切换自动跟进
- **三大呈现模式**：译文跟随（双语对照）/ 译文替换（整页原生中文排版）/ 原文跟随（中文为主、原文注释化）
- **专业级行业翻译**：技术/学术/医疗/法律/金融/电商/游戏/工业八大行业术语库按站点自动匹配，支持自定义术语表
- **国内外双引擎**：Google 免费接口 + 国内极速直连通道（MyMemory）自动降级，无代理也可用
- **交互单元保真**：按钮、导航、标题链接翻译后保留原样式与点击行为；SVG 图标不丢失
- **多语种互译**：英/日/韩/俄/法/德/西/阿拉伯/希伯来/泰/印地等

## 📦 安装（开发者模式）

1. 下载本仓库 `fanyi-lite/` 目录
2. Chrome 打开 `chrome://extensions/` → 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择 `fanyi-lite/` 目录

## 🧪 测试

```bash
node test-dedup.js        # 12 套测试之一：其余见根目录 test-*.js，全量回归
```

仓库根目录下的 `test-*.js` 共 12 套，覆盖去重、并发、术语保护、双引擎降级、SPA 路由、三模式端到端等，全部无依赖、直接运行。

## 📁 结构

```
fanyi-lite/   扩展本体（加载此目录即可使用）
test-*.js     12 套自动化测试（零依赖，node 直接跑）
dist/         商店截图与上架包
```

## 🔒 隐私

偏好设置仅存本地；仅在你触发翻译时，将页面文本发送给你选择的翻译服务。详见 [隐私政策](https://gist.github.com/adhumankind/9a402d04903bb0b38d9d17a25c703111)。
